# 프로젝트 경계 (Project Boundary)

이 문서는 본 저장소(`hazcargo-mobile`, 개발 코드명)와 회사 내부 프로그램 `daniel-oh55/DG_ASSISTANT` 사이의 경계를 명확히 하기 위해 작성되었다.

## 1. 서로 다른 성격의 프로젝트

- `daniel-oh55/DG_ASSISTANT`는 회사 내부 업무용 프로그램이다.
- 본 저장소는 개인이 독립적으로 개발·운영하는 공개 앱 프로젝트다.

## 2. 인프라 분리

- 기존 저장소, 데이터베이스, API, Supabase, Vercel 프로젝트를 사용하지 않는다.
- 신규 앱을 위한 인프라(Supabase, API, 배포 환경 등)는 별도로 구성하며, 이번 PR에서는 아직 만들지 않는다.

## 3. 데이터·자산 분리

- 회사 데이터, 내부 규정, 회사 브랜드, 업무 자료를 사용하지 않는다.
- 기존 저장소의 코드, 이미지, 문구, 환경변수, 설정 파일을 복사하지 않는다.

## 4. 참고 범위

- 기존 프로그램은 사용자 흐름(user flow)과 테스트 사례 분석 목적에 한해 참고할 수 있다.
- 기존 코드나 데이터를 자동으로 재사용하거나 이식하지 않는다.

## 5. 제품 정체성

- 본 저장소는 `DG_ASSISTANT`의 공식 모바일 버전이나 후속 제품이 아니다.
- 별개의 제품 로드맵과 의사결정을 따른다.
