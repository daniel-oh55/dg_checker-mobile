# 데이터 권리 정책 (Data Rights Policy)

## 라이선스 확인 진행 중

- IMO 데이터 사용 허가와 라이선스 확인이 진행 중이다.
- 허가 범위가 확정되기 전까지 실제 IMDG 원문, 표, 데이터를 이 저장소에 추가하지 않는다.

## 기존 회사 자산 미이전

- 기존 회사 데이터베이스와 엑셀 파일의 내용을 신규 앱으로 이전하지 않는다.

## 데이터 출처 기록 원칙

- 저장소에 추가되는 모든 데이터는 출처, 취득일, 버전, 라이선스를 기록해야 한다.
- 기록이 없는 데이터는 저장소에 포함하지 않는다.

## AI 생성 데이터 제한

- AI가 생성한 데이터를 기준 규정 데이터로 사용하지 않는다.

## 샘플 데이터 원칙

- 샘플 데이터도 실제 IMDG 데이터로 오인될 수 있는 값(예: 실제와 동일한 UN번호·Class 조합)을 사용하지 않는다.
