# 안전 원칙 (Safety Principles)

- 본 앱은 위험물 검토를 지원하는 참고 도구이며, 최종 승인 시스템이 아니다.
- 데이터가 누락된 경우 확정적인 판정을 내리지 않는다.
- Class 1(화약류)이 포함된 경우 별도 확인 절차를 안내한다.
- 적용 규정판(edition/version)이 불명확한 경우 판정을 수행하지 않는다.
- 불확실한 경우 보수적으로 안내한다.
- `혼적 가능`, `선적 가능`, `승인` 등의 표현은 제한적으로만 사용한다.
- 실제 규정과 관계 기관, 선사, 항만, 터미널 및 담당자의 최종 확인이 필요함을 항상 안내한다.
