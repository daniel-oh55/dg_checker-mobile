# 제품 범위 (Product Scope)

## 초기 범위

- 위험물 Class 안내
- IMDG UN번호 조회
- 복수 위험물 격리·혼적 판정

## 초기 제외 범위

다음 항목은 초기 버전에서 다루지 않는다.

- 선사별·포트별 선적가부
- SKR/HAL 내부 규정
- 선박·항차·부킹 데이터
- SDS/MSDS AI 판독
- 게시판
- 관리자 기능
- 로그인
- 사고 이력
- 내부 담당자 정보

초기 제외 항목은 향후 별도 PR과 별도 의사결정을 통해 논의될 수 있으며, 이번 PR의 범위에는 포함되지 않는다.
