# ADR 0001: 독립 프로젝트로 구축

## Status

Accepted

## Context

`hazcargo-mobile`(개발 코드명)은 해상 위험물(IMDG) 검토를 지원하는 개인 공개 Android 앱으로 기획되었다. 회사 내부 프로그램인 `daniel-oh55/DG_ASSISTANT`가 유사한 도메인(위험물 Class, UN번호, 격리표)을 다루고 있어, 이를 기반으로 확장할지 완전히 분리된 신규 프로젝트로 시작할지 결정이 필요했다.

## Decision

기존 `DG_ASSISTANT`와 코드, 데이터, 인프라를 공유하지 않는 독립 시스템으로 구축한다.

## Alternatives Considered

- **기존 저장소를 포크하거나 확장**: 회사 내부 코드·데이터·인프라와 얽혀 있어 개인 공개 앱으로 분리하기 어렵고, 회사 자산이 공개 저장소에 유출될 위험이 있다.
- **기존 코드를 일부 복사하여 재작성**: 라이선스·데이터 권리 관계가 불명확해지고, 회사 내부 로직이 공개 앱에 포함될 위험이 있다.

## Consequences

- 신규 저장소, 신규 기술 스택 선택, 신규 인프라(추후 결정)를 처음부터 구성해야 한다.
- 기존 프로젝트의 사용자 흐름과 테스트 사례는 참고할 수 있으나 코드나 데이터를 자동으로 재사용할 수 없다.
- 회사 시스템과의 결합이 없어, 개인 공개 앱으로서 독립적인 배포·운영·라이선스 정책을 자유롭게 결정할 수 있다.
